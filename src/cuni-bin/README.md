# cuni-bin/cuni
CuNi (Code:uNiTY) compiler release binary, copied 2026-10-08 from
~/workspace/cuni-repo/target/release/cuni (built 2026-10-05).

Used by the toll tool cuni-proof via: cuni check <file.cuni> --only <seats> --receipt
The 53-seat gate is limited with --only to seats whose toolchains exist in the
image (js via node, py via python3). The receipt names exactly which seats ran.
